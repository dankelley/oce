# Summarize a met Object

Pertinent summary information is presented, including the sampling
location, data ranges, etc.

## Usage

``` r
# S4 method for class 'met'
summary(object, ...)
```

## Arguments

- object:

  a [met](https://dankelley.github.io/oce/reference/met-class.md)
  object.

- ...:

  further arguments passed to or from other methods.

# Sample adp Data

This is degraded subsample of measurements that were made with an
upward-pointing, moored, ADP manufactured by Teledyne-RDI, as part of
the St Lawrence Internal Wave Experiment (SLEIWEX).

## Usage

``` r
data(adp)
```

## Source

This file came from the SLEIWEX-2008 experiment.

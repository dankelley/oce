# Translate WOCE Units to oce Units

Translate WOCE-style units to oce units.

## Usage

``` r
woceUnit2oceUnit(woceUnit)
```

## Arguments

- woceUnit:

  string holding a WOCE unit

## Value

expression in oce unit form

# Sample lisst Data

LISST (Laser in-situ scattering and transmissometry) dataset,
constructed artificially.

## Usage

``` r
data(lisst)
```

## Source

This was constructed artificially using
[`as.lisst()`](https://dankelley.github.io/oce/reference/as.lisst.md),
to approximately match values that might be measured in the field.

# Save a ctd Object in a CSV File

Writes a comma-separated file containing the data frame stored in the
`data` slot of the first parameter. The file is suitable for reading
with a spreadsheet, or with
[`read.csv()`](https://rdrr.io/r/utils/read.table.html). This output
file will contain some of the metadata in `x`, if `metadata` is `TRUE`.

## Usage

``` r
write.ctd(object, file, metadata = TRUE, flags = TRUE, format = "csv")
```

## Arguments

- object:

  a [ctd](https://dankelley.github.io/oce/reference/ctd-class.md)
  object.

- file:

  Either a character string (the file name) or a connection. If not
  provided, `file` defaults to
  [`stdout()`](https://rdrr.io/r/base/showConnections.html).

- metadata:

  a logical value indicating whether to put some selected metadata
  elements at the start of the output file.

- flags:

  a logical value indicating whether to show data-quality flags as well
  as data.

- format:

  string indicating the format to use. This may be `"csv"` for a simple
  CSV format, or `"whp"` for the World Hydrographic Program format,
  described in reference 1 and exemplified in reference 2.

## Sample of Usage


    library(oce)
    data(ctd)
    write.ctd(ctd, "ctd.csv")
    d <- read.csv("ctd.csv")
    plot(as.ctd(d$salinity, d$temperature, d$pressure))

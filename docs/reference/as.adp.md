# Create an adp Object

Create an adp Object

## Usage

``` r
as.adp(
  time,
  distance,
  v,
  a = NULL,
  q = NULL,
  orientation = "upward",
  coordinate = "enu"
)
```

## Arguments

- time:

  of observations in POSIXct format

- distance:

  to centre of bins

- v:

  array of velocities, with first index for time, second for bin number,
  and third for beam number

- a:

  amplitude, a [`raw()`](https://rdrr.io/r/base/raw.html) array with
  dimensions matching `u`

- q:

  quality, a [`raw()`](https://rdrr.io/r/base/raw.html) array with
  dimensions matching `u`

- orientation:

  a string indicating sensor orientation, e.g. `"upward"` and
  `"downward"`

- coordinate:

  a string indicating the coordinate system, `"enu"`, `"beam"`, `"xy"`,
  or `"other"`

## Value

An [adp](https://dankelley.github.io/oce/reference/adp-class.md) object.

## Details

Construct an
[adp](https://dankelley.github.io/oce/reference/adp-class.md) object.
Only a basic subset of the typical `data` slot is represented in the
arguments to this function, on the assumption that typical usage in
reading data is to set up a nearly-blank
[adp](https://dankelley.github.io/oce/reference/adp-class.md) object,
the `data` slot of which is then inserted. However, in some testing
situations it can be useful to set up artificial `adp` objects, so the
other arguments may be useful.

# Summarize an amsr Object

Print a summary of key components of the object.

## Usage

``` r
# S4 method for class 'amsr'
summary(object, ...)
```

## Arguments

- object:

  an [amsr](https://dankelley.github.io/oce/reference/amsr-class.md)
  object.

- ...:

  ignored.

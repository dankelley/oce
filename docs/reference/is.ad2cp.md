# Test Whether Item is a ad2cp-Type adp Object

Test Whether Item is a ad2cp-Type adp Object

## Usage

``` r
is.ad2cp(x)
```

## Arguments

- x:

  an [oce](https://dankelley.github.io/oce/reference/oce.md) object.

## Value

Logical value indicating whether `x` is an
[adp](https://dankelley.github.io/oce/reference/adp-class.md) object,
with `fileType` in its `metadata` slot equal to `"AD2CP"`.

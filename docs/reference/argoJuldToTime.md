# Convert Argo Julian Day to R Time

Convert Argo Julian Day to R Time

## Usage

``` r
argoJuldToTime(jday)
```

## Arguments

- jday:

  A numerical value indicating the julian day in the Argo convention,
  with day=0 at 1950-01-01.

## Author

Jaimie Harbin and Dan Kelley

## Examples

``` r
argoJuldToTime(25749)
#> [1] "2020-07-01 UTC"
```

# Infer ASCII Code From an Integer Value

Infer ASCII Code From an Integer Value

## Usage

``` r
integerToAscii(i)
```

## Arguments

- i:

  an integer, or integer vector.

## Value

A character, or character vector.

## Author

Dan Kelley

## Examples

``` r
library(oce)
A <- integerToAscii(65)
cat("A=", A, "\n")
#> A= A 
```

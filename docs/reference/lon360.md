# Change Longitude From -180:180 to 0:360 Convention

For numerical input, including vectors, matrices and arrays, `lon360()`
simply calls [`ifelse()`](https://rdrr.io/r/base/ifelse.html) to add 360
to any negative values. For
[section](https://dankelley.github.io/oce/reference/section-class.md)
objects, it changes `longitude` in the `metadata` slot and then calls
itself to handle the
[ctd](https://dankelley.github.io/oce/reference/ctd-class.md) objects
stored as as the entries in `station` within the `data` slot. For this
[ctd](https://dankelley.github.io/oce/reference/ctd-class.md) object,
and indeed for all
non-[section](https://dankelley.github.io/oce/reference/section-class.md)
objects, `lon360()` changes `longitude` values in the `metadata` slot
(if present) and also in the `data` slot (again, if present). This
function is not useful for dealing with coastline data; see
[`coastlineCut()`](https://dankelley.github.io/oce/reference/coastlineCut.md)
for such data.

## Usage

``` r
lon360(x)
```

## Arguments

- x:

  either a numeric vector or array, or an
  [oce](https://dankelley.github.io/oce/reference/oce-class.md) object.

## Examples

``` r
lon360(c(179, -179))
#> [1] 179 181
```

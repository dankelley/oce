# Signal Erroneous Application to non-oce Objects

Signal Erroneous Application to non-oce Objects

## Usage

``` r
# S4 method for class 'vector'
handleFlags(
  object = "oce",
  flags = list(),
  actions = list(),
  where = list(),
  debug = getOption("oceDebug")
)
```

## Arguments

- object:

  A vector, which cannot be the case for `oce` objects.

- flags:

  Ignored.

- actions:

  Ignored.

- where:

  Ignored.

- debug:

  Ignored.

# Summarize an xbt Object

Summarizes some of the data in a `xbt` object.

## Usage

``` r
# S4 method for class 'xbt'
summary(object, ...)
```

## Arguments

- object:

  A [xbt](https://dankelley.github.io/oce/reference/xbt-class.md)
  object.

- ...:

  Further arguments passed to or from other methods.

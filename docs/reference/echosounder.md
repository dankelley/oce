# Sample echosounder Data

This is degraded subsample of measurements that were made with a
Biosonics scientific echosounder, as part of the St Lawrence Internal
Wave Experiment (SLEIWEX).

## Source

This file came from the SLEIWEX-2008 experiment, and was decimated using
[`decimate()`](https://dankelley.github.io/oce/reference/decimate.md)
with `by=c()`.

# Show a Function Argument

Show a Function Argument

## Usage

``` r
argShow(x, nshow = 4, last = FALSE, sep = "=")
```

## Arguments

- x:

  the argument

- nshow:

  number of values to show at first (if length(x)\> 1)

- last:

  indicates whether this is the final argument to the function

- sep:

  the separator between name and value

# Sample landsat Data

This is a subset of the Landsat-8 image designated
LC80080292014065LGN00, an image from March 2014 that covers Nova Scotia
and portions of the Bay of Fundy and the Scotian Shelf. The image is
decimated to reduce the memory requirements of this package, yielding a
spatial resolution of about 2km.

## Details

The original data were downloaded from the USGS earthexplorer website,
although other sites can also be used to uncover it by name. The
original data were decimated by a factor of 100 in longitude and
latitude, to reduce the file size from 1G to 100K.

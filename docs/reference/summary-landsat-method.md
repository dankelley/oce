# Summarize a landsat Object

Provides a summary of a some information about a
[landsat](https://dankelley.github.io/oce/reference/landsat-class.md)
object.

## Usage

``` r
# S4 method for class 'landsat'
summary(object, ...)
```

## Arguments

- object:

  A
  [landsat](https://dankelley.github.io/oce/reference/landsat-class.md)
  object.

- ...:

  Ignored.

# Summarize a section Object

Pertinent summary information is presented, including station locations,
distance along trac, etc.

## Usage

``` r
# S4 method for class 'section'
summary(object, ...)
```

## Arguments

- object:

  An object of class `"section"`, usually, a result of a call to
  [`read.section()`](https://dankelley.github.io/oce/reference/read.section.md),
  [`read.oce()`](https://dankelley.github.io/oce/reference/read.oce.md),
  or
  [`as.section()`](https://dankelley.github.io/oce/reference/as.section.md).

- ...:

  Further arguments passed to or from other methods.

## Value

`NULL`

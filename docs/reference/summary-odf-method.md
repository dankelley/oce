# Summarize an odf Object

Pertinent summary information is presented, including the station name,
sampling location, data ranges, etc.

## Usage

``` r
# S4 method for class 'odf'
summary(object, ...)
```

## Arguments

- object:

  an [odf](https://dankelley.github.io/oce/reference/odf-class.md)
  object.

- ...:

  further arguments passed to or from other methods.

## Value

A matrix containing statistics of the elements of the `data` slot.
